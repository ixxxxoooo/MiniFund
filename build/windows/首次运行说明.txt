MiniFund —— Windows 首次运行说明
=====================================

1. 解压本压缩包，双击 MiniFund.exe 即可运行。
   程序为绿色免安装，数据保存在 %AppData%\MiniFund，日志在 %LocalAppData%\MiniFund\logs。

2. 关于 Microsoft Defender SmartScreen 拦截
   本程序为开源软件，未购买商业代码签名证书，首次运行时
   Windows 可能弹出蓝色提示：「Windows 已保护你的电脑」。
   这不是病毒，处理方式：
       点击「更多信息」→ 点击「仍要运行」。

3. 关于 WebView2 运行时
   程序界面基于 Microsoft Edge WebView2 渲染。Windows 10/11 通常已内置，
   若提示缺少 WebView2，请前往微软官网下载安装「WebView2 Runtime」：
       https://developer.microsoft.com/microsoft-edge/webview2/
