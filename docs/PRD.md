# MiniFund 产品需求文档（PRD）

> 版本：v1.0 ｜ 更新日期：2026-06-12
>
> MiniFund 是一款 macOS 桌面端基金监控工具，基于 Wails3 构建，支持多窗口与系统托盘。
> 范围：国内公募基金（含 QDII，间接覆盖海外市场）。

## 1. 产品定位与用户场景

### 1.1 定位

一款**轻量、常驻、低打扰**的个人基金监控工具：交易时段实时掌握自选基金的估值涨跌与持仓盈亏，无需打开网页或手机 App。

### 1.2 核心用户场景

| 场景 | 描述 |
| --- | --- |
| 盘中扫一眼 | 工作中点击菜单栏托盘图标，弹出迷你面板，3 秒内看完自选涨跌和当日预估盈亏 |
| 持仓盘点 | 打开主窗口，查看持仓总市值、当日预估收益、累计收益 |
| 选基研究 | 搜索基金 → 查看详情（净值走势/重仓股/经理/费率）→ 加自选 |
| 板块轮动观察 | 查看行业板块涨跌热力，判断市场风格 |
| 异动提醒 | 自选基金估值涨跌超过阈值时收到系统通知 |
| 收盘确认 | 晚间净值公布后，自动用真实净值替换估值并重算当日盈亏，可选通知 |

### 1.3 业界对标

- **韭菜盒子（LeekHub / VSCode 插件）**：估值轮询 + 状态栏滚动展示 → 借鉴托盘标题滚动与摸鱼场景。
- **天天基金 App**：自选分组、详情页信息架构 → 借鉴信息组织。
- **蛋卷基金**：持仓收益展示方式 → 借鉴盈亏卡片设计。
- **Stocks（macOS 原生）**：菜单栏即时面板 → 借鉴托盘面板交互。

## 2. 功能需求

### 2.1 基金搜索（P0）

- 全量基金代码表存于本地 SQLite，搜索零网络延迟。
- 支持：基金代码前缀、名称模糊、拼音首字母（如 `hxcz`）、拼音全拼匹配。
- 入口：全局 `Cmd+K` 命令面板（cmdk 风格）+ 侧边栏独立「搜索」页。**标题栏不再放搜索框**，原位置改为展示应用名称「MiniFund」。
- 结果项展示：代码、名称、类型标签；回车进详情，`Cmd+回车` 直接加自选。
- 独立「搜索」页（P0）：基金与**基金公司**统一模糊搜索（代码/名称/拼音首字母/公司前缀），输入即查（防抖）。**默认搜索框垂直居中**，输入关键字后搜索框上移到顶部、下方展示结果表格。结果列（参考基金排行，均取自现有接口、**不新增接口**）：序号 / 基金名称+代码+所属主题标签 / **单位净值(+日期) / 今日 / 近1周 / 近1月 / 近3月 / 近6月 / 近1年 / 近2年 / 近3年 / 今年来 / 成立来（阶段收益异步补全，红涨绿跌）** / 基金类型 / 操作；提供**基金类型筛选**（与基金排行一致：全部/股票型/混合型/债券型/指数型/QDII/FOF，常驻保持，切走再回来不重置）；提供「**列设置**」自定义显示列（持久化，默认隐藏 近2年/成立来，**单位净值/近6月/近3年默认展示**便于直接排序）；**结果列支持点列头排序，且对「全部命中结果」排序（非仅当前页）**——后端一次取齐命中项（最多 300 条，超出则按本地索引顺序截断并提示），**默认不排序（保持命中原始顺序）**；**搜索即预加载全部命中的阶段收益**（分批渐进合并到内存），此后点击列头排序（降序→升序→取消循环）与翻页均直接在已加载的全量数据上进行（内存切片/排序，无需二次等待）；含单位净值/今日/近1周~成立来各阶段收益，补全后自动重排；可加自选或打开详情。**搜索页常驻不清空**：切到其他页再切回时，上次的关键字与结果仍保留。基金/公司搜索统一收敛于此，基金排行与热门主题页不再内嵌就地搜索框。**搜索框默认居中放大**（未搜索态加大字号/高度，便于聚焦输入）。**搜索记录**：默认（未搜索）状态下，搜索框下方以胶囊形式展示最近 10 条搜索关键字（去重置顶、本地持久化，**配色弱化、悬浮显示单条删除按钮**），点击回填并触发搜索，可一键清空。

### 2.2 自选监控（P0，主页面）

- 自选列表支持**分组**（默认分组"自选"，可新建/重命名/删除分组，拖拽排序）。
- **「汇总」默认分类**：分组栏固定第一位、默认选中的虚拟分组，统计**所有分类合并去重**的全部自选与持仓（汇总卡片、持仓占比均按全部计算）。它不可删除、不可作为加自选/移动分组的目标；在汇总视图下加自选落到第一个真实分组、移除则从所有分组彻底移除、移动按钮禁用。汇总为前端虚拟分组（id=0，不入库）。
- 表格列：基金名称/代码（**名称行展示所属主题彩色标签**，与排行/搜索同源）、**今日涨幅**（盘中优先实时估算涨跌；盘后/非交易日回退已公布日涨幅，与排行同源，保证每只都有今日涨幅、不再为空）、最新净值（含日期）、**估算净值**、**当日预估收益**（有持仓时；盘中按估算涨跌、盘后按已确认日涨幅折算，二者皆有数值不再为空）、持仓市值、**持仓占比**（占当前分组持仓总市值）、**持有收益**（累计金额 + 收益率）、**持仓成本**（成本金额 + 成本价）、操作。所有持仓相关列支持列头排序。
- **最新净值与详情页一致**：「最新净值」以权威历史净值（与详情页同源）为准，避免 `fundgz` 滞后导致与详情页对不上；当日净值公布后（或周末/非交易时段），盘中估算已被实际净值取代，估值/估算涨跌列显示"—"，仅盘中（当日净值未确认）展示实时估算。详见 `docs/DATA_SOURCES.md` 2.1 校正策略。
- 交易时段每 30s 自动刷新（频率可配），表头展示"估值时间 HH:mm"。
- 涨跌配色：默认**红涨绿跌**（A 股习惯），设置中可切换绿涨红跌。
- 涨跌幅变化时单元格闪烁动画提示（红/绿背景渐隐）。
- QDII 等无盘中估值基金：估值列显示"—"并标注"无盘中估值"。
- 右键菜单：置顶、移动分组、编辑持仓、设置提醒、独立窗口打开详情、删除。
- 行操作列已提供「**移动到分组**」按钮（下拉选择目标分组，跨分组移动保留持仓/创建时间，合并到目标分组末尾）。
- 列表**默认按加入时间倒序**（最新在前，列头排序可覆盖该默认顺序），并**分页**展示；**每页条数随表格可视高度自适应**（窗口越大每页越多，避免窗口大却一页只有寥寥数条）。
- 所有列表（自选/排行/搜索/主题相关基金/托盘面板）的基金名称行均提供**复制图标**：鼠标悬浮显示，点击快速复制基金代码，复制成功短暂显示对勾。

### 2.3 持仓盈亏（P0）

- 为自选基金录入持仓：以**交易流水**（`position_txn`）为唯一真相源，每笔记录买入/卖出的份额、净值、金额、日期与来源（手动/定投）；持仓份额与成本价由流水**移动加权平均**重算并写入 `position` 派生缓存（份额 = Σ买入 − Σ卖出；买入摊薄均价、卖出不改均价）。
- 持仓编辑弹窗分三块：**持仓概览**（只读派生：总份额/持仓成本/均价/市值/收益）、**交易流水**（加/删，含「快速记一笔」回车提交）、**定投计划**。「直接编辑份额/成本」走「设为基准持仓」（清空该基金流水后写一笔基准买入再重算）。
- **定投计划**（`dca_plan`）：为某基金设定周期（每周/每月）、日期与金额；到期由调度器每自然日检查一次：默认发桌面通知提醒，若开启「自动记一笔」则按 金额 ÷ 最新净值 估算份额自动入账（来源标记 dca），随后推进到下一周期。
- 计算口径：
  - 持仓市值 = 份额 × 最新净值（盘中用估算净值；盘后用已确认净值）
  - 当日预估收益：盘中 = 份额 × (估算净值 − 上一日净值)；净值已确认时 = 份额 × (今日净值 − 昨日净值)，昨日净值由已确认日涨幅反推（保证盘后也有数值）
  - 累计收益 = 份额 × (最新净值 − 成本价)，累计收益率 = 累计收益 ÷ 持仓成本
- **主窗口顶部汇总卡片按「当前分组」统计**（各分组互相隔离、各算各的）：分组持仓市值、当日预估收益（金额+涨跌幅）、累计收益（金额+收益率）、持仓基金数。前端基于实时估值派生计算，随盘中估值实时刷新。
- 净值公布后自动以真实净值重算并落库当日收益记录（用于 v2 收益日历）。
- 隐私：一键"隐藏金额"开关（金额显示为 `****`），快捷键 `Cmd+Shift+H`。

### 2.4 基金详情（P0）

- 打开方式：主窗口内嵌面板（默认）/ 独立窗口（右键或 `Cmd+Enter`）。
- 内容区块：
  1. 头部：名称、代码、类型、最新净值与日涨幅、估算净值实时刷新、**历史最大回撤**标签（**浅红色醒目配色**，提示风险）、**「天天基金主页」按钮**（系统浏览器打开 `fund.eastmoney.com/{code}.html`）；标签行还展示该基金**所属主题/概念彩色标签**（与排行/搜索同源，最多 6 个 + `+N` 折叠，hover 显示全部）。**最新净值卡片**去掉「最新净值」文字标签，改为左侧**上日期下净值**、右侧**放大百分比**展示当日涨跌。
  1.5. **阶段涨幅栅格**：近1月/近3月/近6月/近1年/近3年/成立来（红绿配色，附同类平均），数据源 `FundMNPeriodIncrease`（见 `docs/DATA_SOURCES.md` 2.9）
  2. 净值走势图：单位净值 / 累计净值 / 同类与沪深300对比，区间切换（1月/3月/6月/1年/3年/成立来）；图表带 X 轴时间刻度，鼠标悬停在定位点显示「时间 + 净值」浮窗
  3. 历史净值表：**滚动到底自动加载下一页**（无限滚动），含日增长率
  4. 持仓：**股票持仓（前十重仓股）与债券持仓（重仓债券）分两块、Tab 切换**——有股票持仓默认显示「股票」Tab（可切到「债券」），无股票则默认「债券」；**某类型无数据则不显示对应 Tab**（如纯债基金不显示「股票」、纯股票基金不显示「债券」），两类皆空显示「暂无持仓数据」。股票行展示「名称/代码 + 占比 + 当日涨跌幅（红绿配色）」，点击股票名跳转东方财富对应个股页；债券行展示「代码/名称 + 占净值比例」（数据取自天天基金 f10 债券持仓 `zqcc`，**条目较多时固定行高 + 滚动展示**，避免行高压扁导致文字重叠）
  - 详情窗口加大（默认 1120×840），主区域无整页滚动条（持仓/历史净值各自内部滚动）；有单日限额时展示「单日限额 ¥金额」标签
  5. 基金经理：姓名、任期、任期回报
  6. 基本信息：规模、成立日、费率、跟踪标的（指数基金）

### 2.5 板块与排行（P1）

- 导航入口名为**「热门主题」**，统一为**彩色热力网格**（对齐东财 ztjj 热门主题）：板块类别（**全部/行业/概念**，默认概念；全部=行业+概念合并，CPO/PCB/光模块/算力/液冷 等热门主题即概念板块）+ 排序类别（**按涨幅 / 按资金流入**）。
  - **按涨幅**：ztjj 热门主题（`GetZTJJListNew`，`dt=syl`），阶段可选 **今日 / 近1周 / 近1月 / 近3月 / 今年来**；格子按所选阶段涨跌幅正负与强度着色；点击进入「主题相关基金」列表。
  - **按资金流入**：与「按涨幅」**同源同代码体系**（`GetZTJJListNew`，`dt=zjlr`，主题码 `BK000xxx`）的主力净流入排行，阶段可选 **实时 / 近1周 / 近1月 / 近3月**（对应 `st=FLOW/FLOW_W/FLOW_M/FLOW_Q`，无「今年来」档）；格子按所选阶段净流入金额（亿）正负与强度着色；**点击同样进入「主题相关基金」列表**（不再跳浏览器）。详见 `docs/DATA_SOURCES.md` 2.6。
- **主题相关基金页**：顶部展示该主题的**近期表现面板**（日涨幅、近1周/近1月/近3月/近1年/今年来涨幅及各自的同类排名 `x/总数`，数据源 `GetBKDetailInfoNew`）；下方为该主题相关基金的收益率排行（周期列头排序 + **分页**，按 `TotalCount` 完整覆盖全部相关基金，不再「数据不全」）。
- 已移除过时且与概念板块重复的「基金主题」独立标签（`FundTopicInterface` 主题集老旧、缺热门主题），仅保留其作为板块→相关基金的尽力匹配。
- 基金排行榜：按类型（股票/混合/债券/指数/QDII/FOF）+ 周期（日/周/月/季/半年/年/三年/今年来）列头排序；「单位净值+净值日期」合并为一列（净值在上、日期在下），含**成立来/规模**等字段（规模由移动端批量信息接口 `ENDNAV` 补全，**已去掉手续费列**）；所有列采用**固定列宽**（`table-layout: fixed`），末列为「操作」列（图标 + **加自选** 文字，已在自选中显示「已添加」）；提供「列设置」自定义显示列（持久化）；加载时显示加载动画；双击进详情。
- 基金/基金公司搜索统一收敛到侧边栏独立「搜索」页（详见 2.1），基金排行页与热门主题页不再内嵌就地搜索框，仅保留筛选/排序/分页。
- 排行/搜索列表在每只基金**名称行右侧**展示其**所属主题/概念彩色标签**（如 CPO、电力设备，最多 2 个 + `+N` 折叠，hover 显示全部）；标签颜色按主题名稳定取自 `--chip-*` 分类色票（规避红/绿避免与涨跌混淆），同一主题恒定同色；标签按当前页异步加载并 30 天缓存（详见 `docs/DATA_SOURCES.md` 2.8）。
- QDII 单日申购限额、申购/赎回状态在**基金详情页**以标签展示。
- 大盘涨跌分布仅在**托盘监控面板**展示（标题栏指数条不再附带）。
- 页面可见时才轮询，不可见即停；排行/主题/板块（按全部/行业/概念分键）结果服务层 60s 缓存，启动时预加载默认排行首页与「概念板块」热力。

### 2.5.1 分析 - 基金对比（P1）

- 侧边栏「分析」页含三个工具：收益历史 / 持仓透视 / **基金对比**。
- **基金对比**：搜索或从自选选择 2-6 只基金，对比业绩与净值走势。
  - 「添加对比基金」浮窗支持搜索/自选选择，**失焦自动关闭**。
  - 业绩对比表支持**行列转置切换**：默认「列=基金、行=指标」，一键切换为「行=基金、列=指标」横向对比。
  - **跨页保持**：当前对比的基金集合持久化，切换菜单/重开窗口后仍保留，不被清空。
  - **历史对比**：提供历史对比下拉，记录最近若干批对比组合（可一键恢复、可清空历史）。
  - 提供**清空对比**按钮：清空当前对比集合（≥2 只时先归档进历史）。

### 2.6 指数看板（P1）

- 主窗口顶部常驻指数行情条：上证、深成、创业板、沪深300、恒生、纳指、标普（可配置增删与排序）。**展示全部已选指数**（不再截断为前 5 个），标题栏宽度不足时该指数条内部横向滚动（隐藏滚动条），保证新增指数始终可见。**指数点位数值随涨跌方向着色**（与涨跌幅同色，红涨绿跌跟随 token；摸鱼模式中性色），与行情中心一致。
- 托盘面板复用同一数据。

### 2.7 提醒（P1）

- 规则类型：
  1. 估值涨跌幅阈值（如单日 ≥ +2% 或 ≤ −2%，每日每规则最多触发一次）
  2. 当日净值已公布（可按基金开关）
- 通知方式：macOS 系统通知，点击通知打开对应基金详情。
- 提醒管理页：规则列表、启用开关、触发历史（最近 50 条）。

### 2.8 系统托盘（P0，重点）

- 应用常驻托盘；**关闭主窗口仅隐藏，不退出**，调度器后台继续监控（可在设置关闭此行为）。
- **托盘标题（菜单栏文字）**：可配置展示一只"关注基金"或一个指数的实时涨跌幅（如 `▲1.24%`），多个目标轮播滚动；可关闭只留图标。
- **托盘监控面板**：左键点击托盘图标，在图标下方弹出无边框、置顶小窗（约 320×420）：
  - 顶部：当日预估总盈亏卡片（持仓汇总）
  - 中部：自选估值列表（紧凑行：名称/估算涨跌幅/预估收益），点击行打开主窗口对应详情
  - 底部：指数行情条 + "打开主窗口"/"设置" 入口
  - 失焦自动隐藏；面板打开时估值刷新频率提升至 15s
- **托盘右键菜单**：显示/隐藏主窗口、暂停/恢复监控、摸鱼模式开关、设置、**重启**（启动新实例并退出当前进程）、退出。
- **大盘涨跌分布柱状图**：每根柱顶**常显家数数值**（不再仅悬浮显示），便于直接核对；上涨档用上涨色、下跌档用下跌色，汇总行展示 跌/平/涨 家数。
- **摸鱼模式**：托盘标题与面板中将涨跌幅伪装为中性数字格式（无红绿、无▲▼），主窗口金额自动隐藏。

| 窗口 | 说明 | 特性 |

- frameless 窗口（主窗口/详情窗口）自绘标题栏：**双击标题栏拖拽区最大化窗口，已最大化时双击还原**（与 macOS 原生一致，红绿灯按钮区双击不触发）；左侧红绿灯按钮关闭/最小化/最大化。

- 数据：缓存大小展示与清理、基金代码表手动更新、数据目录打开、**数据备份导出 / 导入恢复**
  - 导出：弹原生保存框，将自选/分组/持仓/收益历史与全部设置导出为单个 JSON 文件（`minifund-backup-时间戳.json`）。
  - 导入：弹原生打开框，校验后**整体替换**自选/分组/持仓/收益历史并合并设置（分组按原 id 恢复，保证条目↔分组映射不丢），恢复后各窗口自动重载。不导出基金代码表/净值等可重建缓存。

### 2.11 财经快讯与 AI 解读（P1）

- **财经快讯页**（侧边栏「财经快讯」），两个 Tab：
  - **全球快讯**：东财全部/全球 7×24 短讯（`kuaixun.eastmoney.com/7_24.html`，`fastColumn=102`，24 小时滚动更新）。由调度器按设置间隔定时拉取，事件推送到所有窗口；重要快讯标红。**（原用基金栏目 `jj.html`/`fastColumn=109`，因其为低频栏目、非交易时段长时间不更新，已改用全部栏目保证持续更新。）**
  - **基金资讯**：东财基金滚动新闻（`roll.eastmoney.com/fund.html`）的完整文章列表，按需加载。
- **定时拉取与通知**：快讯定时拉取，检测到新增条目时（可在设置开关「快讯桌面通知」）弹 macOS 系统通知；**点击通知直接打开该条快讯的独立详情窗口**（通知载荷与页内打开方式一致）；侧边栏「财经快讯」入口显示未读红点，进入页面清零（首轮/重启不补推历史）。
- **逐条已读状态**：快讯/资讯列表项**未读时右侧显示小绿点**，点击打开（阅读）后绿点消失；已读 id **本地持久化**（localStorage，最多保留近 1000 条），重开应用后仍保持已读，避免重复阅读。
- **列表分页与时间倒序**：全球快讯、基金资讯均按时间倒序展示并分页（每页 20 条）；全球快讯列表项展示**完整发布时间（年-月-日 时:分:秒）**，倒序由数据源排序保证。
- **快讯自动刷新**：全球快讯页顶部显示当前时间与倒计时，**倒计时间隔与「设置 - 快讯拉取间隔」保持一致**，归零自动刷新，旁边提供手动刷新按钮（手动刷新会重置倒计时）。
- **点击查看正文（独立窗口）**：点击任一条目打开**独立窗口**（非页内弹窗）展示正文——快讯按其 id 推导文章页尝试抓取完整正文（失败回退短讯），资讯抓取文章页 `#ContentBody` 正文；正文**保留股票/板块超链接（点击经系统浏览器打开个股行情页）与正文图片**，剔除开户引流等广告；窗口内 **AI 解读结果在正文上方展示**，并提供「查看原文」链接。
- **AI 解读（Markdown + 流式输出）**：弹窗内「AI 解读」按钮，调用用户配置的 OpenAI 兼容大模型对该条新闻给出「核心信息 / 可能影响 / 注意要点」的简明解读；未配置时提示前往设置开启。解读以 **Markdown 结构化**返回并由前端渲染（小标题、要点列表、加粗等），且为**流式输出**（边生成边逐字显示，附流式光标），附「仅供参考，不构成投资建议」。
  - 流式推送以「累计全文」为单位（每次事件携带截至当前的完整文本，前端取最长者渲染），**免疫 Wails 高频事件投递的乱序问题**，避免出现文字错乱。

### 2.12 行情中心（P1，首个菜单）

- 侧边栏第一个菜单「行情中心」，也是应用默认进入页面。
- **指数清单（左侧）**：按「A 股 / 港股 / 美股」分组展示常见指数（上证、深证、创业板、科创50、北证50、沪深300、上证50、中证500、中证1000、恒生、道琼斯、纳斯达克、纳斯达克100、标普500），每行展示最新点位与涨跌幅，**点位与涨跌幅同色**（涨跌色用 `--quote-up/--quote-down` token，摸鱼模式统一中性色）。实时报价由调度器**每 30s 主动刷新**并经 `market:center` 事件推送（全天候、独立于交易时段，覆盖美股 CN 夜盘；前端不自行轮询）。
- **右侧行情区**：顶部头卡（指数名称 + 分组标签 + 最新点位 + 涨跌额/涨跌幅 + 日/周/月分段切换），其下为当日 OHLC 概览（今开/最高/最低/**成交额**），再下为 K 线图。**成交额按各市场本币展示并标注币种**：A 股「元」、港股「港元」，**不做汇率换算**（量纲不同，显式标注币种避免误读；无数据则显示「—」）。**美股成交额来源不稳定，不展示该项**。成交额取自实时报价（腾讯简易行情成交额字段），非 K 线。
- **K 线图**：选中指数的蜡烛图（基于 `klinecharts`），含量能柱、MA5/MA10/MA20 均线与十字光标浮窗（日期 / OHLC / 量）；高度随窗口自适应；支持 **日 K / 周 K / 月 K** 周期切换。
  - **交互**：滚轮缩放、拖拽平移；**向左滚动到最左侧时动态加载更多历史**（初始预加载 500 根，逐步升至上限 1000 根）。
  - **缓存**：历史 K 线落 SQLite 长期缓存（`kline_cache`），重开瞬时渲染；数据源不可用时回退缓存离线展示。
  - 颜色全部映射主题 token，随明暗主题 / 涨跌色方案 / 摸鱼模式实时切换。
- 数据源：实时报价统一走**腾讯**（稳定，覆盖全部）；K 线按市场分源 —— A 股主要指数/港股走腾讯，**北证 50 走新浪 A 股 K 线、美股走新浪美股 K 线**（腾讯对这两类仅返回最新一根；新浪日线 + 服务端聚合周/月），东财 `push2his` 仅作最后兜底。详见 `docs/DATA_SOURCES.md` 3.4。

## 3. 监控时间策略（核心设计）

> 目标：在数据最新鲜的时段勤快、其余时间零请求，省资源且降低被风控概率。

### 3.1 时段状态机

| 状态 | 时间窗口（交易日） | 行为 |
| --- | --- | --- |
| `PreMarket` | 09:15–09:30 | 拉取一次指数与昨日净值兜底数据，不轮询 |
| `Trading` | 09:30–11:30、13:00–15:00 | 估值轮询（默认 30s）+ 指数轮询（10s 合并请求） |
| `Lunch` | 11:30–13:00 | 暂停估值；指数行情低频（60s，港美股仍在交易则保持） |
| `NavConfirm` | 16:00–23:00 | 每 10 分钟轮询当日真实净值；某基金净值确认后停止该基金轮询；全部确认或到 23:00 结束 |
| `Idle` | 其余时间/非交易日 | 全部暂停，零网络请求 |

- QDII：跳过 `Trading` 估值轮询；在次日 `NavConfirm` 窗口抓取净值。
- 港股/美股指数：若用户订阅，`Trading` 之外按各自市场交易时段单独调度（港股 09:30–16:00，美股北京时间 21:30–04:00，低频 60s）。

### 3.2 交易日历

- 内置 A 股年度节假日表（随版本更新），周末直接排除。
- 兜底：若日历过期（跨年未更新），退化为"仅排除周末"，并在设置页提示更新。

### 3.3 用户感知

- 所有数据展示处统一标注数据时间（"估值 14:32" / "净值 06-11"）。
- 非交易时段 UI 顶部展示状态徽标："已收盘 · 下次更新 16:00 净值确认"。

## 4. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 100 只自选下托盘面板打开 < 300ms；估值刷新一轮 < 2s（并发 ≤ 8） |
| 资源 | 后台常驻内存 < 150MB；Idle 状态 CPU 占用近似 0 |
| 离线 | 无网络时展示最近缓存数据并标注时间，不白屏不报错弹窗 |

| 平台 | v1 目标 macOS（arm64 优先）；架构不阻碍后续 Windows 移植 |
