## 风险跟踪

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 非官方接口变更/风控 | 估值/详情不可用 | datasource 隔离 + 熔断降级 + 备源调研（见 DATA_SOURCES.md） |
| Wails3 alpha API 变动 | 升级成本 | 锁定 alpha 版本号，升级单独提交 |
| 估值与真实净值偏差 | 用户误解 | UI 全程标注"估算值，仅供参考" |
