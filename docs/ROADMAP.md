## 里程碑 M1：数据通道（v1.0 基础）

2. `internal/datasource` 公共设施：http.Client、JSONP/JS 解析、GBK 解码、限频器、熔断器（依赖：无）
3. `eastmoney`：基金代码表拉取 + 入库 + 本地搜索（依赖：1、2）
4. `eastmoney`：盘中估值批量拉取（依赖：2）
5. `tencent`/`sina`：指数行情 + 主备降级组合器（依赖：2）
6. `internal/scheduler`：交易日历 + 时段状态机 + 估值/指数轮询任务 + 事件广播（依赖：4、5）
